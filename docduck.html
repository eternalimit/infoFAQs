DocDuck by LightOn

Generate synthetic documents to test optical character recognition (OCR) and document understanding.

How it works

DocDuck generates pages with varied layouts and typography. Each page comes with the expected text and bounding boxes that identify where each block appears. You can compare your model’s output with those reference values to see what it read and located correctly.
